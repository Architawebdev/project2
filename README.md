# Weather App 🌤️

A responsive weather application built using HTML, CSS, and JavaScript. It fetches weather data using the OpenWeather API.

## Features

- Search weather by city
- Temperature in Celsius
- Feels-like temperature
- Weather condition and icon
- Humidity
- Wind speed
- Loading message
- Error handling
- Enter key support
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## How to Run

1. Clone or download the repository.
2. Create a `config.js` file.
3. Add your OpenWeather API key.
4. Open `INDEX.HTML` using Live Server.

> Note: `config.js` is ignored by Git so the API key is not uploaded to GitHub.
